## 4. 개발 중 발견하고 고친 오류

| 오류 | 원인 | 조치 |
|---|---|---|
| 자율주행 차가 정지선 0.5m 앞에서 멈춰 결정을 기다리지 않음 | 감속 판정 경계 | 정지 거리 기반 속도 곡선으로 교체, 단위 테스트 추가 |
| 구간이 바뀌는 프레임에 충돌로 잘못 집계 | 이전 구간 기준으로 판정 | 현재 구간 기준으로 판정 |
| 6×6·7×7 미로에 목표로 가는 길이 없음 | 미로 설계 오류 | 미로 수정, BFS 도달 테스트 추가 |
| 자율주행·탐정단·아레나가 진행 중 오류 화면으로 빠짐 | effect가 함수 대신 객체를 반환(React 19가 정리 함수로 호출) | `report`가 값을 반환하지 않도록 수정. E2E가 "올바른 게임의 결과 화면"인지 검사하도록 강화 |
| 자막이 게임 화면을 가림 | 자막이 화면 위에 겹침 | 발판 안내 위 전용 자막 띠로 분리 |
| 체험 중 관리자가 그래픽 품질·학년·시간을 바꾸면 진행 중인 게임이 깨짐(3D 장면 재생성, 미로 크기 불일치, 타이머 재시작) | 게임이 설정을 실시간으로 읽음 | 게임 시작 시점의 설정을 고정. 바뀐 설정은 다음 체험부터 적용 |
| 학습 데이터 배열이 렌더마다 새로 만들어져, 다시 그려지면 학습이 처음부터 재시작될 수 있음 | 배열을 매번 새로 생성 | `useMemo`로 고정 |
| AI 관찰 단계(자동 주행·학습 관찰)에서 무입력 경고 | 입력이 필요 없는 장면도 무입력으로 판단 | 관찰 장면에서는 무입력 타이머 정지(`useWatching`) |

## 5. 아직 테스트하지 않은 것

- 실제 O/X 발판 하드웨어와 설치 현장 대형 모니터 (장치 미확보)
- 장시간(수 시간) 연속 가동 — 20회 연속 체험까지만 자동 확인
- 저사양 PC에서의 자동 품질 조절 동작 (개발 PC는 고사양)
- 무입력 복귀는 시간을 5초/20초로 줄여 확인했고, 기본값(25초/90초) 그대로 기다리는 테스트는 하지 않음
