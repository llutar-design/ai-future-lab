# 관리자 사용 설명서

## 관리자 메뉴 열기

1. 발판과 별도로 연결한 키보드에서 **Ctrl + Shift + M**을 누릅니다.
2. 비밀번호를 입력하고 Enter. 초기 비밀번호는 **2580**입니다. 설치 직후 [통계 · 데이터] 탭에서 바꾸세요.
3. 5번 틀리면 60초 동안 잠깁니다. 닫기: **Esc**.

관리자 화면이 열려 있는 동안 발판 입력은 게임으로 전달되지 않습니다(진단 화면에만 표시).
학생은 발판만 사용하므로 관리자 메뉴에 들어갈 수 없습니다. 키오스크에는 키보드를 치워 두는 것을 권장합니다.

## 탭별 기능

### 게임 · 시간
| 항목 | 설명 |
|---|---|
| 게임 활성화 | 체크를 끄면 메인 메뉴에 "점검 중"으로 표시되고 O 발판 순환에서 건너뜁니다 |
| 체험 시간 | 게임별 2~20분. 시간이 끝나면 그때까지의 결과로 결과 화면이 나옵니다 |
| 학년별 난이도 | 1~2 / 3~4 / 5~6학년. 데이터 개수, 미로 크기(5×5/6×6/7×7), 사례 수, 조사 횟수가 바뀝니다 |
| 결과 화면 표시 | 기본 15초 후 메인 메뉴로 자동 복귀 |
| 무입력 안내 반복 | 기본 25초마다 안내 음성과 "발판을 밟으면 계속" 화면 |
| 무입력 시 메인 복귀 | 기본 90초 동안 입력이 없으면 게임을 끝내고 메인 메뉴로 |

### 발판 · 진단
- **발판 입력 테스트**: 발판을 밟으면 O/X 칸에 불이 들어오고, 기록에 "수락" 또는 "무시(이유)"가 표시됩니다.
  - 길게 밟음: 키 반복 무시 · 떨림 무시: 디바운스 · 잠금 중: 직전 입력 직후 · 동시 입력: 두 발판을 함께 밟음
- **키 매핑**: "키 추가"를 누른 뒤 발판(또는 키)을 밟으면 그 키가 등록됩니다. 같은 키가 반대쪽에 있으면 자동으로 옮겨집니다.
- **입력 타이밍**: 디바운스(120ms), 입력 후 잠금(350ms), 동시 입력 판정(70ms). 아이들이 너무 빨리 넘어가면 잠금을 늘리세요.
- **장치 연결 상태**: 게임패드형 HID 발판은 목록에 이름이 나옵니다. 키보드형 발판은 운영체제에서 일반 키보드와 구분되지 않아 "입력 테스트"로 확인합니다.

### 화면 · 소리
| 항목 | 설명 |
|---|---|
| 그래픽 품질 | 자동(FPS 45 미만이면 해상도를 낮춤) / 높음 / 보통 / 낮음(그림자·비 입자 감소, 30fps 배경) |
| 화면 맞춤 | 비율 유지(1920×1080 기준, 여백 가능) / 꽉 채우기 |
| FPS 표시 | 화면 오른쪽 위에 프레임 수 표시 |
| 전체 화면 키오스크 | Electron에서 전체 화면·키오스크 모드 전환 |
| 음량 · 효과음 · 음성 안내 · 속도 | 효과음은 프로그램이 직접 합성(파일 없음), 음성은 Windows 한국어 음성 사용 |

한국어 음성이 없으면 "설치된 한국어 오프라인 음성이 없습니다"라고 나오고 자막만 표시됩니다.
Windows 설정 › 시간 및 언어 › 음성 › 음성 추가 › 한국어(Microsoft Heami)를 설치하세요.

### 통계 · 데이터
- **이용 통계**: 게임별 전체/오늘 이용 횟수, 완료율(시간 초과가 아닌 비율), 평균 체험 시간. 학생 이름 등 개인정보는 저장하지 않습니다.
- **학습 모델 초기화**: 자율주행 "누적 학습 데이터"를 지웁니다.
- **게임 데이터 · 설정 초기화**: 모든 설정을 기본값으로 되돌립니다(비밀번호는 유지).
- **자율주행 누적 학습**: 켜면 이전 학생들이 만든 판단 데이터(최대 500개)를 이어서 학습에 사용합니다. 기본은 꺼짐(매 학생 새로 시작).
- **오류 로그**: 프로그램 오류, 관리자 로그인, 장시간 무입력 복귀 등이 시간과 함께 최대 500개까지 저장됩니다.

### 시스템
CPU 코어, GPU 이름, 해상도, JS 메모리 사용량, 실행 환경(Electron/브라우저)을 보여줍니다.
"메인 메뉴로 이동", "프로그램 새로고침", "프로그램 종료"(Electron) 버튼이 있습니다.

## 운영 팁
- 매일 시작: PC 켜기 → (시작프로그램 등록 시) 자동 실행. 발판 입력 테스트로 O/X 확인.
- 프로그램이 멈춘 것처럼 보이면: 관리자 메뉴 › 시스템 › 프로그램 새로고침. 렌더러가 죽으면 자동으로 다시 불러옵니다.
- 게임 중 오류가 나면 "작은 문제가 생겼어요" 화면 후 5초 뒤 메인 메뉴로 돌아가고 오류 로그에 기록됩니다.
- 설치 전 PC 점검: `scripts\check-system.ps1` 실행 → `system-check.txt`.
