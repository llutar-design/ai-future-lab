# AI 교육 원리 설명 자료 (선생님·운영자용)

각 연구소에서 화면에 나오는 숫자는 모두 프로그램이 그 자리에서 실제로 계산한 값입니다.
"실제 학습"과 "시뮬레이션"은 화면에 태그로 구분해 표시합니다.

| 태그 | 의미 |
|---|---|
| 실제 학습 중 / 실제 평가 / 실제 Q-learning | 학생 입력으로 모델을 학습하거나 평가한 값 |
| 가상 센서 시뮬레이션 | 자율주행 센서 값은 3D 장면 정보에서 만든 가상 값(카메라 영상 분석 아님) |
| 사전 분석된 사례 | 딥페이크 탐지 점수는 교육용으로 미리 적어 둔 값(실제 탐지 모델 아님) |

---

## 1. AI 훈련 연구소 — 지도학습

**흐름**: 기준 정하기 → 로봇 10~18마리 분류(데이터 만들기) → 신경망 학습 → 처음 보는 로봇 시험 → 틀린 것 고쳐 재학습 → 최종 시험

- **모델**: 입력 12개(색 4 + 크기 1 + 모양 3 + 무늬 3 + 안테나 1) → 은닉 8개(tanh) → 출력 2개(softmax). 손실은 교차 엔트로피, 최적화는 Adam, 150회 반복.
- **학습/검증**: 학생 데이터의 약 25%를 그룹 비율에 맞춰 떼어 두고(층화 분할) 학습에 쓰지 않습니다. "학습 정확도"(공부한 문제)와 "검증 정확도"(처음 보는 문제)를 따로 보여줍니다.
- **AI도 실수**: 시험 단계에서 AI는 확신도(softmax 확률)와 함께 답합니다. 맞았는지는 학생이 판정합니다. 확신도가 높아도 틀릴 수 있다는 점을 보여줍니다.
- **재학습**: 틀린 사례를 정답으로 고쳐 데이터에 추가하고 새 모델을 학습합니다. 최종 시험 6문제는 학생이 먼저 정답을 정하고, 재학습 전/후 모델을 같은 문제로 채점합니다. 결과가 좋아지지 않을 수도 있으며 그대로 보여줍니다.
- **잘못된 데이터 실험**: 같은 데이터의 라벨 약 30%를 일부러 뒤바꿔 학습한 모델도 같은 시험으로 채점해 비교합니다.
- **데이터 편향**: 그룹별 데이터 수(막대그래프)와 색깔별 분포표를 보여주고, 한 그룹이 2배 이상 많으면 경고합니다. 최종 시험의 그룹별 정확도가 크게 다르면 "편향"이라고 알려줍니다.

**지도 포인트**: "왜 검증 정확도가 학습 정확도보다 낮을까?", "기준을 중간에 바꾸면 AI는 어떻게 될까?"

## 2. AI 자율주행 연구소 — 판단 학습과 안전 설계

**흐름**: 교통 상황 8~12개 판단(데이터) → 학습 → AI 혼자 주행 테스트 → AI 판단 승인/재검토 → 재학습 → 최종 미션(학교 가는 길)

- **입력**: 신호등(없음/초록/노랑/빨강), 보행자(없음/인도/횡단 중), 장애물, 어린이 보호구역, 날씨(맑음/비/안개), 앞차(없음/멀리/가까움) → 15개 숫자 → 신경망(15→8→2) → 출발/정지.
- **평가**: 교통 규칙으로 정답을 붙인 가상 상황 60개(학습에 쓰지 않음)로 정확도를 계산하고, 재학습 전후를 같은 60문제로 비교합니다.
- **AI와 안전 제어기 분리**: AI(학생 데이터로 학습)는 "제안"만 합니다. 별도의 규칙 기반 안전 제어기가 빨간불·횡단 보행자·장애물·가까운 앞차·보호구역 보행자를 확인하고, 위험하면 AI나 학생의 결정과 관계없이 정지선을 넘지 못하게 막습니다. 갑자기 나타난 장애물은 긴급 제동합니다. 그래서 학생이 일부러 잘못 골라도 충돌이 일어나지 않습니다(단위 테스트: 무작위·최악 판단 80회 주행 충돌 0회).
- **가상 센서**: 위험도·센서 신뢰도(맑음 97%, 비 82%, 안개 64%)·감지 물체 목록은 장면 정보에서 계산한 시뮬레이션 값입니다.

**지도 포인트**: "AI가 확신 90%로 출발하자고 했는데 왜 안전 제어기가 멈췄을까?", "실제 자동차에 안전 장치가 여러 겹인 이유"

## 3. AI 딥페이크 탐정단 — 근거 기반 미디어 검증

**흐름**: 첫인상 추리(O/X) → 증거 3~4개 조사 → 탐지기 결과(사전 분석) → 최종 판단 → 정답과 근거 공개 (사건 3~4개)

- **사례 5개**(모두 이 프로그램을 위해 그린 가상 자료, 실제 인물·기관 아님)
  1. 운동장의 펭귄 떼 — AI 생성 (출처 기록, 그림자 방향)
  2. 쌍무지개 — **실제** (이상해 보여도 과학적으로 맞음)
  3. 교장선생님 발표 영상 — 딥페이크 (공식 공지와 불일치)
  4. 우주 놀이터 그림 — **사람이 그림** (탐지기가 AI로 잘못 의심 = 오탐)
  5. 폭설 휴장 기사 — 가짜 기사 + 옛날 실제 사진 재사용 (이미지 탐지기는 못 잡음)
- **증거 6종**: 이미지 세부 표현, 그림자와 반사, 배경 일관성, 출처 정보, 생성 이력·메타데이터, 교차 검증. 각 증거에 "강한/중간/약한 근거, 판단 근거 아님"을 표시해 한 가지 단서로 단정하지 않도록 합니다.
- **탐지기**: 설치된 로컬 탐지 모델이 없으므로 "사전 분석된 사례 · 실제 AI 분석 아님"으로 표시하고, 탐지기의 한계(오탐·미탐·글/재사용 판단 불가)를 함께 보여줍니다.
- **결과**: 나의 판단, 확인된 사실, 불확실한 부분, 추가로 확인할 것, 탐지의 한계.

**교육 메시지**: "AI가 만든 콘텐츠는 매우 자연스러울 수 있습니다. 눈으로 보는 것뿐 아니라 출처와 근거를 확인해야 합니다."

## 4. AI 강화학습 아레나 — 보상과 시행착오

**흐름**: 보상 규칙 선택 → 학습 관찰(최대 400 에피소드) → 배운 대로 주행 → 규칙 바꿔 재학습 → 챔피언십(학습 전 / 1차 / 2차)

- **알고리즘**: 표 형식 Q-learning. Q(s,a) ← Q(s,a) + α[r + γ·max Q(s′,·) − Q(s,a)], α=0.5, γ=0.95. 탐험률 ε는 1.0에서 에피소드마다 ×0.985(최소 0.05).
- **상태**: 칸 위치 × 모은 에너지 아이템 조합. **행동**: 상하좌우.
- **보상 규칙**: 목표 +10, 충돌 −1, 걸음마다 −0.1(빠른 도착), 에너지 +2, 위험 구역 −10(에피소드 종료).
- **화면**: 에피소드 수, 탐험률, 최근 20회 성공률, 누적 보상 곡선, 성공률 곡선, 이동 경로, 충돌 횟수. 화살표는 각 칸에서 Q값이 가장 큰 방향(로봇이 배운 길)입니다.
- **챔피언십**: 같은 미로에서 탐험 없이 각 로봇을 20번 실행해 목표 도달률, 평균 이동 거리, 평균 소요 시간(1걸음=0.5초), 평균 충돌 횟수를 측정합니다. 학습 전 로봇은 Q값이 모두 0이라 무작위로 움직입니다.
- **보상 설계의 함정**: 목표 보상을 끄고 걸음 벌점만 주면, 로봇이 빨리 끝내려고 위험 구역에 뛰어드는 행동을 배웁니다(단위 테스트로 확인). 성공이 보장되지 않으며 결과를 조작하지 않습니다.

**교육 메시지**: "AI는 보상을 최대화하도록 행동을 학습합니다. 어떤 보상을 주는지가 매우 중요합니다."
