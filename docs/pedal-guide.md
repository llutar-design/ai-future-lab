# O/X 발판 연결 설명서

## 지원하는 발판 방식

| 방식 | 지원 | 설명 |
|---|---|---|
| 키보드형 USB HID (대부분의 USB 발판 스위치) | ✅ | 발판을 밟으면 정해진 키(예: A, D, ←, →, F1…)를 보냅니다 |
| 게임패드형 USB HID (조이스틱/버튼 박스) | ✅ (관리자에서 켬) | 표준 Gamepad API로 버튼 번호를 읽습니다 |
| 시리얼(COM) / 전용 드라이버 / 무선 전용 수신기 | ❌ | 제조사 프로토콜이 확인되지 않아 지원하지 않습니다 |

> 실제 발판 장치의 프로토콜은 아직 확인되지 않았습니다. 아래 절차로 어떤 방식인지 먼저 확인하세요.

## 1. 발판이 어떤 방식인지 확인하기

1. 발판을 PC USB에 꽂습니다.
2. 메모장을 열고 O 발판, X 발판을 차례로 밟습니다.
   - 글자가 입력되면 → **키보드형**입니다. 어떤 글자가 나오는지 적어 둡니다.
   - 아무것도 안 나오면 → `Win + R` → `joy.cpl` 실행. 목록에 장치가 보이면 **게임패드형**입니다.
   - 둘 다 아니면 → 제조사 설정 프로그램에서 "키보드 모드"로 바꿀 수 있는지 확인합니다.

## 2. 키보드형 발판 설정

기본 매핑: **O = A 또는 ←**, **X = D 또는 →**.
발판이 다른 키를 보낸다면:
1. Ctrl + Shift + M → 비밀번호 → [발판 · 진단]
2. O 발판 옆 "키 추가" → O 발판 밟기 → 등록됨
3. X 발판도 같은 방법
4. "발판 입력 테스트"에서 O/X 칸에 불이 들어오고 "수락"이 뜨는지 확인

키 코드는 한/영 상태와 관계없이 동작합니다(물리 키 위치 기준).

## 3. 게임패드형 발판 설정

1. [발판 · 진단] › "게임패드형 발판 사용" 체크
2. 발판을 밟은 채로 "지금 눌린 버튼"에 나오는 번호(예: `#0-2` → 버튼 2)를 확인
3. O 버튼 번호, X 버튼 번호에 입력

## 4. 입력 안정화 기능

| 기능 | 동작 | 기본값 |
|---|---|---|
| 키 반복 방지 | 발판을 계속 밟고 있어도 한 번만 입력 | 항상 |
| 디바운싱 | 같은 발판이 짧은 시간 안에 다시 눌리면(접점 떨림) 무시 | 120ms |
| 입력 후 잠금 | 입력이 받아들여진 뒤 잠시 모든 입력 무시(연타 방지) | 350ms |
| 동시 입력 처리 | 두 발판을 거의 동시에 밟으면 둘 다 무시하고 "하나씩 밟아 주세요" 안내 | 70ms |
| 오래 서 있기 안내 | 4초 넘게 발판을 밟고 있으면 "발을 떼었다가 다시 밟아 주세요" | 항상 |

## 5. 문제 해결

| 증상 | 확인 |
|---|---|
| 아무 반응이 없음 | 메모장 테스트로 키 입력이 되는지, 관리자 진단에서 "밟음"이 기록되는지 |
| 한 번 밟았는데 두 번 넘어감 | 디바운스 시간을 200ms 이상으로 |
| 너무 둔하게 반응 | 입력 후 잠금을 250ms 정도로 줄이기 |
| 기록에 "동시 입력"이 자주 뜸 | 두 발판 간격을 넓히거나 동시 입력 판정을 40ms로 줄이기 |
| 창 밖을 클릭한 뒤 입력이 안 됨 | 프로그램 창에 포커스가 있어야 키 입력이 들어옵니다. 키오스크 모드(Electron)에서는 항상 포커스 유지 |
