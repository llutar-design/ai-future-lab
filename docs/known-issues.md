# 오류 및 미구현 기능 목록

현재 버전(1.0.0)에서 알려진 한계와 아직 구현하지 않은 부분입니다. 숨기지 않고 모두 적었습니다.

## 하드웨어 · 장치

| 항목 | 상태 | 설명 |
|---|---|---|
| 실제 O/X 발판 장치 확인 | ⚠ 미확인 | 발판 실물/프로토콜을 확인하지 못했습니다. 키보드형·게임패드형 USB HID만 지원하며, 실제 장치로 [발판 연결 설명서](pedal-guide.md)의 절차를 거쳐야 합니다 |
| 시리얼/전용 드라이버 발판 | ❌ 미구현 | 프로토콜 확인 후 `src/input/`에 어댑터를 추가해야 합니다 |
| 키보드형 발판 "연결 상태" 표시 | ⚠ 제한 | 운영체제가 일반 키보드와 구분하지 않아 "연결됨/끊김"을 자동 판별할 수 없습니다. 진단 화면의 입력 테스트로 확인합니다 |
| 대형 모니터 실측 | ⚠ 미확인 | 개발 PC(2560×1600)와 1920×1080 헤드리스 화면으로만 확인했습니다. 설치 현장의 모니터에서 글자 크기·가독성 확인이 필요합니다 |

## 게임별

| 게임 | 항목 | 상태 | 설명 |
|---|---|---|---|
| 딥페이크 탐정단 | 실제 탐지 모델 | ❌ 미설치 | 검증된 로컬 탐지 모델이 없어 탐지 점수는 모두 **"사전 분석된 사례"**로 표시합니다. 연동 구조(`detector.ts`)만 준비되어 있습니다 |
| 딥페이크 탐정단 | 사진·영상 자료 | ⚠ 대체 | 실제 사진/영상 대신 직접 그린 SVG 그림과 애니메이션을 사용합니다(저작권·초상권 문제 없음). 실제 교육용 사진을 쓰려면 사용 권한을 확보한 뒤 `cases.tsx`에 추가하세요 |
| 자율주행 | 카메라 영상 인식 | ❌ 해당 없음 | 객체 인식은 실제 영상 분석이 아니라 장면 데이터 기반 **가상 센서 시뮬레이션**이며 화면에 그렇게 표시합니다 |
| 자율주행 | 교차로 회전·다른 차량 주행 AI | ❌ 미구현 | 차량은 직선 도로를 달리며, 앞차는 단순 이동만 합니다 |
| 강화학습 | 알고리즘 | ⚠ 제한 | 표 형식 Q-learning만 제공(DQN 등 신경망 강화학습 없음). 미로는 학년별 3종 고정 |
| 훈련 연구소 | 데이터 수 | ⚠ 제한 | 체험 시간상 데이터가 10~18개로 적어 검증·시험 정확도가 크게 흔들립니다. 화면에도 이 점을 안내합니다 |
| 공통 | TensorFlow.js | ⚠ 대체 | 권장 스택의 TensorFlow.js 대신 의존성 없는 TypeScript 신경망을 사용했습니다(작은 모델이라 더 빠르고 테스트 재현이 쉬움). 교체 방법은 [architecture.md](architecture.md) |
| 공통 | React Three Fiber · Phaser | ⚠ 미사용 | 자원 해제를 직접 통제하기 위해 Three.js를 직접 사용했고, 2D 화면은 SVG/Canvas로 충분해 Phaser는 쓰지 않았습니다 |

## 운영 · 기타

| 항목 | 상태 | 설명 |
|---|---|---|
| 음성 안내 | ⚠ PC 의존 | Windows 한국어 음성(Microsoft Heami)이 설치된 PC에서만 음성이 나옵니다. 없으면 자막만 표시합니다 |
| 관리자 화면이 열린 동안 | ⚠ 참고 | 게임 타이머는 계속 흐릅니다(일시 정지 기능 없음) |
| Alt+F4, Ctrl+Alt+Del | ⚠ 참고 | 운영체제 단축키는 프로그램이 막을 수 없습니다. 키보드를 치워 두거나 Windows 할당된 액세스(키오스크 모드) 사용을 권장합니다 |
| 결과 화면 이후 기록 | 참고 | 개인정보 없이 게임 이름·시간·완료 여부·요약 수치만 저장합니다 |
| 다국어 | ❌ 미구현 | 한국어만 지원 |
| 실행 파일 서명 | ⚠ 미서명 | 코드 서명 인증서가 없어 처음 실행 시 Windows SmartScreen 경고가 나올 수 있습니다("추가 정보 → 실행") |
| 프로그램 아이콘 | ⚠ 기본값 | Electron 기본 아이콘을 사용합니다. `build/icon.ico`를 넣고 다시 빌드하면 바뀝니다 |
